# XXD Panel 076 オリジナルスタイル指示 · 日本語参考訳

アップロードした各写真を、それぞれ独立した上質なデザインポスターにしてください。複数写真を組み合わせず、一枚ずつ出力します。全体は3:4の縦位置で、上下二領域を厳密に同じ高さの1:1、各50%とします。

上部には元写真を忠実に残し、主体の同一性と数、人物や動物の姿勢、建築構造、地形関係、観察角度、空間方向、実在素材、自然な光と影、元の色彩の空気を正確に維持します。旅行誌、独立出版物、写真展級のごく軽いカラー調整と極薄のフィルム粒子だけを加えます。イラスト化せず、主体を移動、増減、反転、伸縮、再造形しません。

下部では、写真で最も識別性の高い**主体、輪郭、姿勢、物語上の関係**を抽出し、東洋的な余白を持つ**濃色クレヨン速写**へ再解釈します。写真の全画角を複製せず、背景を逐一描きません。同一性、場面の意味、感情に不可欠な手掛かりだけを残し、濃色クレヨン、木炭、色鉛筆のような粗い線で形を探し直します。輪郭は途切れ、反復、ずれ、微かな震えを許し、短いハッチング、擦れ、重ね線で局所的な重さをつくれますが、重要な比率、方向、姿勢は一目で認識できる正確さを保ちます。

写真の情報密度を引き継がず、構図を再設計します。主体の**視覚重心、運動方向、正負形、空間的緊張**から偏置、縮小、局部拡大、開放構図を選び、見えないグリッドと非対称バランスで制御します。主体を明確な一領域に集中し、他を積極的に削除して、約45%以上の連続した余白を保ちます。余白は空、空気、距離、水面、地面を直接表す完全で静かな「場」です。少数の線、色面、輪郭は主要境界を越えてもよく、抑制の中に意外性と呼吸を生みます。

素材は**濃色クレヨン速写線＋少量のマットなガッシュ／アクリル色面**です。紙目、蝋の摩擦、粒状の途切れ線、乾いた縁、紙の露出、不均一な被覆を残します。局部は少し厚く実在感を持たせ、オイルパステルや乾性油彩の触感を示せますが、全面厚塗りにはしません。複雑な植生、建築、人物、環境の細部は積極的に概括し、写実的精密描写を目指しません。

色は上の写真から**最も温かく、明るく、鮮やかで、人間味のある手掛かり**を探して再調整し、実際の色値を複製しません。高明度で透明感があり、柔らかいが甘すぎないマカロン色へ変換します。元写真からクリームアプリコット、ピーチピンク、コーラルオレンジ、バターイエロー、若芽グリーン、ミントシアン、晴空ブルー、ラベンダーパープルなどを自然に導き、穏やかな寒暖関係で層をつくります。日光、衣服、花、壁、生活の細部が残した楽しい記憶のように、明るくても眩しくなく、柔らかくても灰色にしません。濃色クレヨン線が画面を安定させ、少量の鮮やかな暖黄、桃紅、コーラルを感情の焦点にします。森系の暗緑、土褐色の支配、汚れたモランディ化、古びた黄変、蛍光色、安価なキャンディ感は避けます。

文字は写真の主体、場所、動作、記憶、感情から自由に生成し、固定タイトルや固定言語を設けません。**小さく抑制され、わずかな機械誤差を持つタイプライター書体**を使います。主体の動勢、余白の縁、見えないグリッド、クレヨン線の間に配置し、広い字間、微小なずれ、縦組み、不完全な整列で編集リズムをつくります。通常の見出しとして上から載せるのでなく、私的な観察記録や芸術出版物の欄外注記として画面と共同で構成します。

全体は**濃色クレヨン線、明るいマカロン色面、天然紙、大きな余白、精緻なマイクロタイポグラフィ**による人間的で癒やしのある気質です。温かく、ゆるく、敏感で、生き生きとし、少し不器用でありながら、成熟した構図秩序と芸術出版感を持たせます。完全な背景、密集した写実細部、太い漫画線、カートゥーン化、子供のクレヨン画、整いすぎたデジタル筆、3Dレンダリング、ECイラスト、テンプレートポスターは避けます。
